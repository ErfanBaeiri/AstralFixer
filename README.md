# 💡 BugFixer - A Modern Q&A Platform Built with .NET 9

BugFixer is a full-featured, modern Question & Answer web application inspired by [Stack Overflow](https://stackoverflow.com/), developed using **.NET 9** and following **Clean Architecture** principles.

Whether you're seeking knowledge or helping others grow, BugFixer provides a rich, interactive platform that brings developers together.

---

## 🚀 Features

- 🧠 **Post & Answer Questions** – Ask technical questions and provide helpful answers.
- ⭐ **Voting System** – Upvote or downvote both questions and answers to surface quality content.
- ✅ **Accepted Answers** – Mark the best answer to help future visitors quickly find solutions.
- 📌 **Bookmark Questions** – Save interesting questions to your personal list for later review.
- 📧 **Email Activation** – Secure account verification via activation codes sent by email.
- 👤 **Custom Avatars** – Let users upload and choose their own profile images.
- 🧹 **Clean Architecture** – Scalable, testable, and maintainable codebase.
- 🗃️ **Repository Pattern** – Abstraction for data access, making the system easy to extend and test.
- 🖊️ **Rich Text Editor (CKEditor 5)** – Create beautifully formatted content.
- 📅 **Modern UI Components** – Including WaitMe loader, DatePicker, MagicSuggest for tags.
- 📈 **Interactive Charts with Chart.js** – Visualize user activity and trends.
- 📊 **Real-Time Features with SignalR** – Real-time online user count is displayed using SignalR, keeping everyone instantly updated as users join or leave.
---

## 🛠️ Tech Stack

- **Backend**: ASP.NET Core 9 Web API
- **Authentication**:  Email Verification
- **Database**: SQL Server + Entity Framework Core 9
- **Real-Time**: SignalR
- **Libraries**:
  - `CKEditor5` for rich content editing
  - `Chart.js` for data visualization
  - `WaitMe` for loading indicators
  - `MagicSuggest` for tag suggestion
  - `Bootstrap Datepicker`
- **Architecture**: Clean Architecture + Repository Pattern
